# AI-Driven Automated News Video Generation Platform

> An AI-powered multimedia platform that automatically transforms PIB news articles into engaging short-form videos using Generative AI techniques.

---

# 📌 Overview

This project automates the process of converting textual news content into professional AI-generated videos. The system integrates multiple AI modules including text summarization, image generation, voice synthesis, and automated video rendering to create dynamic multimedia news content.

The platform was designed to streamline digital content creation workflows for news/media organizations and government information broadcasting systems.

---

# 🚀 Features

- 📰 Automatic News-to-Video Conversion
- ✍️ AI-based Text Summarization
- 🖼️ AI Image Generation
- 🔊 Text-to-Speech Voice Narration
- 🎬 Automated Video Rendering
- 📱 Responsive Flutter Frontend
- ⚡ API-Based Processing Pipeline
- 📂 Downloadable Video Outputs

# ▶️ Installation

## Clone Repository

```bash
git clone https://github.com/your-username/AI-News-Video-Generation.git
cd AI-News-Video-Generation
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

## Run Backend

```bash
python app.py
```

## Run Flutter Frontend

```bash
flutter pub get
flutter run
```
